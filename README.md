# Uddhar — Discrete Mathematics Reels

Private production repository for Uddhar's short-form Discrete Mathematics explainer series.

## Start here
1. Read `CLAUDE.md`.
2. Read `README_FIRST.md` if present in the project starter package.
3. Follow `series/WHITEBOARD_STYLE.md` and the other `series/` reference documents.
4. Use the project-scoped Claude Code skill at `.claude/skills/whiteboard-style/SKILL.md`.

## Episode workflow
Each episode lives in `episodes/EPXX-topic/`.
Keep scripts, briefs, references, source code and subtitles versioned.
Keep generated renders out of Git; upload final MP4s to a separate asset store or GitHub Release if suitable.

## Security
This repository may contain unpublished scripts, voice recordings and brand assets. Keep it private.
Never commit API keys, access tokens, `.env` files, credentials, student personal data or other secrets.
