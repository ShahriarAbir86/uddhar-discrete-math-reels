# Uddhar Whiteboard Video Brand Guideline

## Brand reference
This is a video-specific application of Uddhar Brand Guideline Design v2.1. If the official brand guideline or user provides a newer asset/decision, newer specific instruction wins.

## Visual identity
- Background: white or warm white, clean and calm.
- Main ink / headings: Deep Navy `#101B49`.
- Highlight / key action: Primary Orange `#F2530F`.
- White: `#FFFFFF`.
- Light neutral: `#F6F6F7`.
- Bengali type: Hind Siliguri.
- English type: Plus Jakarta Sans.
- Logo: latest supplied official primary logo or icon only. Do not recreate it from text, screenshot, or memory.
- If official logo file is missing, leave a clearly documented placeholder or ask the user to upload it. Do not fake it.

## Whiteboard adaptation
The main content should feel hand-drawn on a clean academic whiteboard:
- navy marker strokes for structure, equations, labels and arrows;
- orange marker for the active concept, key transition, selected node or final answer;
- subtle light-neutral panels only when needed;
- realistic marker reveal / stroke drawing, with consistent line weight;
- controlled imperfection is acceptable; illegibility is not.

## Avoid
- Old U-shaped logo / superseded artwork.
- Old Phitron blue-yellow palette.
- Purple-neon-lime as the default current Uddhar identity.
- Full-screen decorative gradients, glow, heavy shadows, stock icons, excessive grid, clutter, fake handwritten fonts.
- Logo on a busy background without a clean holding area.
- Too many colours competing with navy and orange.

## Logo handling
Use the exact master asset from `brand/assets/`. Preserve proportions and clear space. Prefer primary lockup on light background. At small size use official icon asset if supplied. Do not add shadow, outline, glow, bevel or 3D effects.
