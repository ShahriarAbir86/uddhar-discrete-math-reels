# New episode

Copy this folder to `episodes/EPXX-short-topic/`, then add:
- `inputs/script.md` (approved Bangla script)
- `inputs/voiceover.mp3` (ElevenLabs export, untouched)
- `inputs/inspiration/` (reference images; optional)
- `brief.md` from `series/EPISODE_TEMPLATE.md`
Then run: `/whiteboard-style Plan EPXX` — stops at the storyboard for approval.
