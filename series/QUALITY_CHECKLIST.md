# Uddhar Whiteboard Reel — Quality Checklist

## Academic accuracy
- [ ] One clear learning objective.
- [ ] Definitions and formulas verified.
- [ ] Every algebraic transformation is valid.
- [ ] Example assumptions and domain are stated.
- [ ] Metaphor is clearly separated from formal proof.
- [ ] CS application is accurate and not overstated.
- [ ] References file supports the factual claims.

## Brand
- [ ] Current Uddhar logo asset used, not recreated.
- [ ] Deep Navy `#101B49` and Primary Orange `#F2530F` are used consistently.
- [ ] White/light neutral background.
- [ ] Hind Siliguri for Bangla and Plus Jakarta Sans for English.
- [ ] No old U-shaped mark or obsolete palette.
- [ ] Logo proportions and clear space preserved.

## Visual
- [ ] One continuous diagram / spatial composition.
- [ ] Camera moves through the same composition.
- [ ] Picture precedes explanatory text.
- [ ] Labels are attached to relevant objects.
- [ ] <=7 explanatory words visible at once where practical.
- [ ] Equations are large enough to read on a phone.
- [ ] One meaningful motion at a time.
- [ ] No template-like slide transitions, stock icons, glow or random decoration.
- [ ] Keyframes reviewed before full render.

## Audio and subtitles
- [ ] Exact user voiceover used.
- [ ] Actual duration checked.
- [ ] Script/audio mismatch flagged.
- [ ] Subtitle timing aligned to speech.
- [ ] Bengali glyph shaping checked.
- [ ] No clipping or abrupt audio cut.
- [ ] Music, if any, does not compete with speech.

## Technical
- [ ] 1080×1920.
- [ ] 9:16.
- [ ] 60fps.
- [ ] H.264 MP4 / yuv420p (or explain exception).
- [ ] Duration matches voiceover within expected tail tolerance.
- [ ] No missing frames, black flashes or broken paths.
- [ ] No off-screen labels or cut-off logo.
- [ ] Final file opens and plays.

## Delivery
- [ ] Final MP4.
- [ ] Editable/source project.
- [ ] SRT subtitle file.
- [ ] Storyboard / scene timing.
- [ ] Keyframe contact sheet.
- [ ] QA report.
- [ ] Production notes and references.
